1. Get the project

Clone the repository or download the current release to your computer.

2. Install Dynare

The launcher finds MATLAB and Dynare automatically. Dynare 6.4 is the currently validated version.

3. Start the simulator

.\start_windows.ps1 on Windows or ./start_mac_linux.sh on macOS/Linux.
